INSTALL

설치 방법

💻 PC (윈도우)

  1. 위의 PC 다운로드를 눌러 압축 파일을 받아요.
  2. 압축을 풀고 EvaProject.exe를 실행해요.
  3. 파란 경고 창이 뜨면 추가 정보 → 실행을 눌러요.
  4. 닉네임과 비밀번호를 정해 시작해요.

📱 안드로이드 폰

  1. 폰에서 안드로이드 다운로드를 눌러 파일을 받아요.
  2. 받은 파일을 열어 설치해요.
  3. '출처를 알 수 없는 앱' 안내가 뜨면 허용해요.
  4. PC에서 쓰던 닉네임·비밀번호로 로그인하면 이어서 할 수 있어요.

가입할 때 나오는 복구 코드는 꼭 적어 두세요. 비밀번호를 잊었을 때 필요해요. 새 버전이 나오면 게임이 알아서 업데이트를 안내해요. 아이폰은 아직 지원하지 않아요.
